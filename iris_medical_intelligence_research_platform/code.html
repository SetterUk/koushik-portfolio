13 // ARCHITECTURAL TRADE-OFFS

THE HARD PART WASN'T MAKING A CHATBOT.

Putting a system into production exposes the gulf between a slick demo and an enterprise tool that oncologists trust with clinical trial intelligence.

01 / SCALE & CHUNKING

Data Scale vs Memory

Millions of OpenAlex records blow past edge memory quotas. Migrated from naive bulk ingestion to streamed Inngest step workers processing bounded cursors with zero RAM exhaustion.

02 / IDENTITY

Disambiguation Collisions

"Y. Zhang" matches over 2,400 clinical researchers. Implemented deterministic institution cross-matching (ROR) paired with ORCID and co-author overlap heuristics to prevent false profile mergers.

03 / TRANSLATION

Structured SQL vs Vector Drift

Vector embeddings struggle with exact numerical ranges ("trials initiated after Q2 2023"). Combined hybrid pgvector embeddings with strict SQL WHERE parameters generated by the Intent Agent.

04 / LATENCY

Graph Traversal Under 100ms

Computing co-author graphs dynamically across 50,000 publications crippled database pools. Pre-computed denormalized adjacency tables during nightly ingestion runs to deliver instant UI graphs.

05 / PROVENANCE

Zero Generative Fluff

Enforced an abstract syntax tree citation validator on the LLM response output. If an asserted paper does not possess a verified DOI in the retrieval set, the pipeline rejects and recalculates.

rule_settings Rigor Over Convenience Every system decision privileged clinical truth over generative simplicity.
14 // POST-MORTEM LOGBOOK

BUILD → BREAK → TRACE → FIX

3 INCIDENTS RESOLVED
[FAIL_01] INNGEST HTTP 504 TIMEOUT

Unpaginated author extraction query attempted to aggregate 85,000 records in a single synchronous serverless invocation.

FIX: Decomposed payload into recursive 2,000-item micro-batches with automatic cursor advancement.
[FAIL_02] EMBEDDING COSINE DRIFT

Acronym collision between "APC" (Adenomatous Polyposis Coli tumor suppressor) and "APC" (Antigen Presenting Cell).

FIX: Injected biological ontology MeSH parent prefixes into vector chunk metadata prior to embedding.
[FAIL_03] CASCADE DELETION RACE

Author entity deduplication worker locked Postgres foreign key tables during simultaneous user queries.

FIX: Re-architected deduplication to soft-tombstoning using asynchronous merge views and non-blocking locks.

17 // PERSPECTIVE

WHAT I LEARNED.

"AI is only as good as the information around it."

The fanciest LLM in the world outputs confident nonsense if your ingestion layer lacks author disambiguation and clean relational grounding.

"Retrieval is a system problem, not just a prompt."

Telling a model to "be accurate" achieves nothing. You must design deterministic retrieval boundaries, typed schema handoffs, and verification ASTs.

"Building the product is different from building the demo."

Handling background worker retries, database connection pooling, and sub-100ms graph queries represents 85% of real AI engineering.
