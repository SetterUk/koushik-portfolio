THE PHILOSOPHY

EDITORIAL AXIOM
AI ≠ THE WHOLE PRODUCT.

The language model belongs strictly at the translation and explanation interface, not at the ground-truth calculation layer.

Health decisions should never depend on a generative model hallucinating micronutrient numbers, guessing allergic cross-reactivity, or improvising glycaemic index scores based on probabilistic text prediction.

If a peanut allergy check is 99% confident, that means 1 in 100 times it will fail. In e-commerce, a 1% error is an apology email; in clinical allergen tracking, it is an anaphylactic reaction.

Therefore: Math and deterministic rules must run the verification. The AI's sole duty is to translate that verified verdict into concise, sympathetic, human language.

PILLAR 03 // SLM RUNTIME MEDIAPIPE · GEMMA 2B

ON-DEVICE AI (GEMMA / MEDIAPIPE)

Integrated Google's Gemma 2B model quantized to INT4 via MediaPipe LLM Inference API. Prompt-constrained so the model is physically prevented from fabricating facts.

// Strict prompt injection format
PROMPT: <start_of_turn>user

<end_of_turn><start_of_turn>model

By passing pre-calculated deterministic facts into the prompt, the model cannot invent ingredients.

ENGINEERING MATURITY

The hard part wasn't the model. It was deciding where the model should not be used.

Three non-negotiable engineering trade-offs made to ensure clinical reliability on resource-constrained consumer hardware.

01

TRUST & DETERMINISM

Critical calculations require mathematical certainty. Generative models fluctuate on identical seeds; pure functional Kotlin routines never fail to compute exact milligram limits.

Rule: Zero probabilistic logic on safety.
02

OFFLINE & MEMORY BUDGET

Running a 2B parameter model within a 1.5GB mobile RAM envelope alongside active CameraX buffers required aggressive memory mapping and lazy tensor instantiation.

Envelope: < 1.5GB mobile memory cap.
03

PERSONALIZATION OVER GENERALITY

Contextualizing thresholds without relying on generic cloud heuristics. A food item isn't universally "good" or "bad"—it is purely an evaluation against the user's metabolic reality.

Constraint: Individualized metabolic lens.
FAILURE LOG // ROOT CAUSE ANALYSIS
POST-MORTEM #02 · CLICK ACCORDIONS TO EXPAND
BUILD → BREAK → LEARN → REBUILD

Crumpled packaging, memory panics & cold truths

01. Foil Wrapper OCR Failures expand_more

Crumpled and reflective packaging distorted bounding boxes. Incomplete token fragments caused Gemma to hallucinate ingredients. → Fixed with strict confidence gating: if OCR confidence < 85%, prompt user to scan barcode instead.

02. Android Low-Memory Killer (LMK) Terminations expand_more

Model loading spike collided with active camera buffer (exceeding 2.2GB RAM). Mid-range test devices terminated the background app instantly. → Fixed with quantized memory-mapped tensors and downscaling preview buffer to 720p.

03. 500k Row SQLite Query Spikes expand_more

Initial unindexed FTS queries caused 200ms frame drops on cold starts. → Fixed via compound prefix indexing and pre-compiled FTS5 tables, bringing query time to 7.8ms.

RETROSPECTIVE

Building it changed how I think about AI.

Three foundational engineering principles solidified through months of physical device testing.

01

NOT EVERYTHING NEEDS A MODEL.

If a problem can be solved with arithmetic, hash-maps, or finite state automata, never deploy a probabilistic neural network. Reserve LLMs solely for ambiguous linguistic synthesis.

02

RIGOROUS SYSTEMS EMBRACE AI.

The model is an ergonomic interface, not the entire stack. Real-world machine learning success lives in the caching schemas, data cleaning pipelines, and fail-safe deterministic guards around it.

03

“WORKS ON MY MACHINE” IS MEANINGLESS.

An AI model that takes 8 seconds over a cellular cloud connection is useless to a mother balancing groceries with a toddler in an aisle. Local-first, fast, and tactile utility is what transforms software into a trusted tool.
